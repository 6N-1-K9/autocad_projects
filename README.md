# Машинная графика и начертательная геометрия

Учебные работы по дисциплине **«Машинная графика и начертательная геометрия»**, выполненные преимущественно в AutoCAD.

В репозитории сохранились отдельные чертежи, промежуточные версии и фрагменты работ.

## Содержание

* построение и моделирование 3D-призмы;
* построение видов геометрических объектов;
* выполнение разрезов и сечений;
* построение пересечения поверхностей;
* оформление чертежей в рамках форматов A3 и A4.

## Технологии

* AutoCAD
* DWG
